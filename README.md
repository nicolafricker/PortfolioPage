# PortfolioPage
A GitHub page as a digital business card showcasing realized projects, experience with various technologies, and a framework for my personal skills.

## Getting Started

To run the application locally, follow these steps:
1. **Navigate to the project directory**:
   ```bash
   cd PortfolioPage
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the application**:
   ```bash
   npm start
   ```

4. **Open your browser** and go to `http://localhost:5173` to view the application.
